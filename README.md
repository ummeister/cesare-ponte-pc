# Cesare Ponte PC per Windows

Il programma che collega il tuo computer al tuo dipendente artificiale (Cesare, Luca, Perla), così può
usare i programmi del PC che gli autorizzi tu.

**Scarica l'ultima versione:**
https://github.com/ummeister/cesare-ponte-pc/releases/latest/download/CesarePontePC-Windows.zip

Come si usa:
1. Estrai lo zip (tasto destro → «Estrai tutto…») e apri `CesarePontePC.exe`.
   Se Windows mostra «PC protetto da Windows»: «Ulteriori informazioni» → «Esegui comunque».
2. Inserisci il codice di collegamento che trovi nel tuo pannello, alla pagina «Ponte PC».

Il programma non contiene password né chiavi: senza il codice di collegamento del tuo pannello non fa niente.
Non si installa e si toglie cancellando la cartella.

Questo repository contiene solo i rilasci del programma, non il suo codice.
